# KINU
### KINU Is Not Unix
KINU is a small project aiming to emulate a tiny CLI based OS from bare scratch. From actuall emulated hardware.
> **CPU -> Assembler -> Programming Language(SEC C) -> Kernel(KINUx) -> Operating System(KOS)**
* KINU is rn private and not in a presentable form it will be public soon.
KINU is primarily an educational and experimental project. The goal is not to compete with existing operating systems, compilers, or CPUs, but to understand how they work by building the pieces myself like a GIGACHAD.
